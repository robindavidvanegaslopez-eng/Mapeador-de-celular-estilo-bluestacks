# Mapeador de Toques

Botones en pantalla que simulan dedos (toque, mantener, turbo, deslizar, joystick, macros),
con teclado externo opcional. Android 8.0+ (detección automática de joystick: Android 11+).

## Compilar (GitHub Actions)
Sube el contenido de esta carpeta a un repositorio. La pestaña **Actions** compila solo
y deja el APK como artefacto `MapeadorToques-debug`.

## Primer uso
1. Abre la app → "Abrir ajustes de accesibilidad" → activa **Mapeador de Toques**.
   (Android 13+: si sale en gris, Información de la app → ⋮ → "Permitir ajustes restringidos".)
2. Quita la optimización de batería desde la propia app.
3. Toca la burbuja flotante → **Editar botones** → **Añadir**.
